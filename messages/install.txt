CodeContinue - AI Code Autocomplete & Chat for Sublime Text
============================================================

🚀 FIRST THINGS FIRST: RUN THE SETUP WIZARD
--------------------------------------------
1. Press: Ctrl+Shift+P  (or Cmd+Shift+P on macOS)
2. Type:  CodeContinue: Configure
3. Press: Enter

The step-by-step setup wizard will configure everything in under 30 seconds:
  1. Completion Endpoint & Model (auto-detects models from server)
  2. Dual-Engine Chat Endpoint & Model (local runner or cloud like Claude/GPT)
  3. 1-Click Keybinding Setup (Recommended: Ctrl+Enter Suggest, Tab Accept, Esc Dismiss)


QUICK START
-----------
1. Open any Python, C++, or JavaScript file
2. Press Ctrl+Enter to trigger a code suggestion at cursor
3. Press Tab to accept the inline suggestion (gray ghost text)
4. Press Escape to dismiss a suggestion
5. Right-click any code to Chat about Selection or Rewrite with Edit Selection


KEYBINDINGS REFERENCE
---------------------
When you run "CodeContinue: Configure", the wizard installs the recommended
shortcuts directly into your User keymap without conflicts:

• Suggest on-demand:   Ctrl+Enter  (code_continue_suggest)
• Accept suggestion:   Tab         (code_continue_accept, active only when visible)
• Dismiss suggestion:  Escape      (code_continue_dismiss, active only when visible)

To customize your keybindings manually at any time:
  Preferences > Package Settings > CodeContinue > Key Bindings
  (or Ctrl+Shift+P >> "Preferences: CodeContinue Key Bindings")


ENDPOINTS & DUAL-ENGINE SETUP
-----------------------------
Local Server (LM Studio, Ollama, vLLM):
  Endpoint: http://localhost:8000/v1/chat/completions (or your local IP:port)

Anthropic (Claude 3.5 Sonnet / Haiku):
  Endpoint: https://api.anthropic.com/v1/messages

OpenAI (GPT-4o, etc.):
  Endpoint: https://api.openai.com/v1/chat/completions

You can also switch models on the fly anytime via:
  Ctrl+Shift+P >> "CodeContinue: Switch Model..."
