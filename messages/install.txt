CodeContinue - AI Code Completion for Sublime Text
=====================================================

Welcome! CodeContinue is now installed and ready to use.

SETUP
-----
On your first use, you'll be prompted to configure:
1. Your API endpoint (OpenAI-compatible or Anthropic)
   Default: http://localhost:8000/v1/chat/completions
2. Your model name (auto-detected or entered manually)
3. Your API key (optional, for cloud providers)

You can also configure anytime via Command Palette:
  Ctrl+Shift+P >> "CodeContinue: Configure"

Or manually:
  Preferences >> Package Settings >> CodeContinue >> Settings


DEFAULT KEYBINDING (not implemented, you have to set it up once)
---------------------------------------------------------------
By default, no keybindings are enabled to prevent conflicts with your existing setup.

To set up your keybinding:
1. Open the Key Bindings split view:
   Preferences > Package Settings > CodeContinue > Key Bindings
   (or Ctrl+Shift+P >> "Preferences: CodeContinue Key Bindings")
2. Copy the keybinding settings from the LEFT side (default template).
3. Paste them into the RIGHT side (your User keymap file) inside [ ... ].
4. Save the file (Ctrl+S on Windows/Linux, Cmd+S on macOS).

Example configuration to paste on the right side:
[
    {
        "keys": ["ctrl+enter"],
        "command": "code_continue_accept"
    }
]

If you prefer using Tab:
[
    {
        "keys": ["tab"],
        "command": "code_continue_accept",
        "context": [
            { "key": "code_continue_visible", "operator": "equal", "operand": true }
        ]
    }
]


QUICK START
-----------
1. Open a Python, C++, or JavaScript file
2. Press Enter at the end of a line - suggestions auto-trigger!
3. Press your configured accept key (e.g. Ctrl+Enter or Tab) to accept the suggestion (gray inline text)
4. For multi-line suggestions, press the accept key multiple times


ENDPOINTS & MODELS
------------------
Local Server (e.g., Ollama, LM Studio, vLLM):
  Endpoint: http://localhost:8000/v1/chat/completions
  Model: Your local model name

OpenAI:
  Endpoint: https://api.openai.com/v1/chat/completions

Anthropic:
  Endpoint: https://api.anthropic.com/v1/messages
